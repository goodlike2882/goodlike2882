## Проекты

### [Конструктор договоров](https://goodlike2882.github.io/contract-constructor/)

Анкета, из которой собирается договор в Word. Четыре вида: лицензионный договор на ПО, поставка, оказание услуг, подряд.

- Не даёт скачать договор без существенных условий: предмета и способов использования для лицензии (ст. 1235, 1270 ГК РФ), наименования и количества товара для поставки (ст. 455, 506), предмета услуг (ст. 779), результата и сроков работ (ст. 702, 708).
- Сверяет ИНН и расчётный счёт с БИК по контрольным цифрам.
- Собирает .docx со стилями, многоуровневой автонумерацией и перекрёстными ссылками на пункты. Шаблоны оформлены по принципам юридического дизайна.
- Строит схему договора на одну страницу: кто что передаёт, порядок и сроки, санкции и споры. Номера пунктов на схеме ведут к тексту договора, схему можно распечатать.
- Работает в браузере: введённые данные никуда не отправляются.

### [Проверка open source лицензий](https://goodlike2882.github.io/oss-license-check/)

Находит сторонние компоненты программы и их лицензии и показывает, что из этого следует для юриста.

- Читает папку проекта в браузере: lock-файлы npm и Composer, установленные пакеты npm и Python, Maven, Go, Cargo, SBOM в форматах CycloneDX и SPDX. Лицензию определяет по метаданным, тексту файла LICENSE и пометкам SPDX в исходниках.
- Оценивает компоненты с учётом модели распространения (передача копий, онлайн-сервис, внутреннее использование) и способа подключения. Находит конфликты: закрытый продукт с GPL-кодом, AGPL в закрытом сервисе, GPL-2.0-only рядом с Apache 2.0, запрет коммерческого использования.
- Собирает отчёт в Word: конфликты с объяснением, обязанности по лицензиям, перечень компонентов и формулировку для лицензионного договора.
- Файлы проекта не отправляются на сервер.
